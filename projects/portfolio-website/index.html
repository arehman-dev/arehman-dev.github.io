ARCHITECTURAL CONTEXT & SCOPE

Evolved across three major iterations—from a single-page vanilla HTML/CSS/JS showcase (v1), to a multi-page Astro technical portfolio paired with a separate Jekyll blog (v2), into a unified Astro v6 static platform (v3.0). The root workspace (/) serves as a high-signal engineering portfolio featuring an interactive Neofetch terminal, 50+ item Toolbelt, project architecture deep-dives, certifications, and technical articles. Simultaneously, /me/ provides a contemplative editorial space inspired by Paul Stamatiou and Dario Amodei for essays ('Perspective'), bilingual RTL Urdu Nastaliq poetry ('Ashaar'), commonplace collections, and photography ('Tasweer-Kahani').

02 //

BOTTLENECK ANALYSIS & IMPLEMENTATION

Target Bottleneck & Friction

Maintaining two separate static site generators (Jekyll in Ruby and Astro in Node.js) across split repositories created deployment friction, duplicated assets, and disconnected theme states between the technical portfolio and personal writings.

Systems Architecture Solution

Consolidated both spaces into a single, strictly typed Astro v6 static build (50 static routes) with distinct layout shells (BaseLayout for / and PersonalLayout for /me/) that share a unified Pitch Black OLED (#000000) & Frosted White Acrylic Glass palette, synchronized localStorage theme state, and multi-mode Reading Comfort themes—while preserving v1 and v2 in zero-bloat Git tags and archive branches.

03 //

VERIFIED SUBSYSTEM CAPABILITIES

  • Unified Single-Repo Architecture (v3.0): 50 pre-rendered static routes across Technical Portfolio (/) and Personal Space (/me/) with instant bridge navigation
  • Pitch Black OLED & Frosted Glass System: Synchronized Light and #000000 OLED Dark themes with anti-FOUC inline initialization and dual Emerald/Sapphire ambient glows
  • Eye-Comfort Reader Mode Engine: Persistent 4-mode reading switcher (Default, Warm Sepia, Sepia Dark, and Soft E-Ink Contrast) across both technical and personal articles
  • Bilingual Editorial & Visual Storytelling (/me/): Open-canvas essays, RTL Noto Nastaliq Urdu poetry typography, keyboard navigation (h/p/t/a), and a filterable fullscreen lightbox gallery ('Tasweer-Kahani')
  • Zero-Bloat Version Archiving: Complete historical preservation of v1 (Vanilla JS) and v2 (pre-merger Astro) via annotated Git tags and archive branches with 0 KB working-tree overhead
