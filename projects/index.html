Problem Statement:

Traditional PDF text extractors (pdftotext) fail due to corrupted legacy Nastaliq font CMaps that scramble character mappings and strip Arabic diacritics, while standard OCR engines like Tesseract break on central page watermarks and multi-column conjugation grids.

Systems Implementation:

Engineered a zero-SDK, multithreaded Python CLI tool utilizing Poppler page rendering, concurrent ThreadPoolExecutor workers, automatic model fallback, and idempotent per-page state recovery to produce a 100% diacritic-accurate digital corpus.

  • 100% preservation of Arabic diacritics (Zabar, Zer, Pesh, Sukun, Tanween, Shaddah) and verbatim Urdu Nastaliq orthography
  • Automatic conversion of complex grammatical paradigm grids (Gardan) and vocabulary lists into Markdown tables
  • Concurrent worker pool (-w flag) with automatic rate-limit backoff and model fallback
